# La Ribera de Ñuble Conecta — web y descarga Android

Interfaz pública de la aplicación escolar. La carpeta downloads del repositorio publicado contiene el APK de prueba y su huella SHA-256. Estos archivos se mantienen aparte del paquete web. Este repositorio no contiene el servidor, credenciales ni datos escolares. La API valida autenticación y permisos en Supabase.
